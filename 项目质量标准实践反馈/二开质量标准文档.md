  【Web端开发】二开质量标准文档

1. 概述
1.1 目的
本规范针对数字孪生大屏 B&S 架构二开项目，建立分级化、可量化、可落地的质量标准体系，明确不同交付等级下 UI高保真还原、屏幕适配、3D场景镜头/光照/功能、前端动效与交互反馈的质量标准，保障项目交付质量。
1.2 适用范围
适用于所有标准化的行业非标应用/前端Web开发/前端定制项目需求的 B&S 架构二开项目。
1.3 等级约定
项目立项时，需在需求文档、合同中明确最终交付等级 L1 POC演示级 / L2 标准交付级 / L3 极致Demo级，所有开发、测试、验收工作均以对应等级指标为唯一基准。
2. 使用说明
1. 立项阶段：结合客户需求、使用场景、预算及交付目标，确定质量等级，同步至需求文档与项目排期
2. 开发阶段：开发人员严格按照对应等级的各项指标开展编码、样式、场景定制工作。
3. 测试阶段：测试人员依据本标准逐项校验，标注不合格项并推动整改。
4. 验收阶段：甲乙双方以约定等级指标作为验收依据，全部指标达标方可完成项目验收。
